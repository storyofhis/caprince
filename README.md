## How To Contribute 
### 1. Clone Repository
after you clone the repository of your current branch you have to ensure everything is already updated
### 2. Create New Branch 
if you want to change or create another feature you have to ensure you are in your own branch. make sure your branch name is easy to understand [link](https://medium.com/@abhay.pixolo/naming-conventions-for-git-branches-a-cheatsheet-8549feca2534)
```
git checkout -b <new-branch-name>
```
### 3. Commit the Current Changes
you have to commit the current changes by giving any specific message. here's structure from the guidelines of the message you have to know : 
```
<type>(<scope>): <subject>
```
here's the command you should to know : 
- feat: create new feature
- fix: fix bugs
- perf: change code to make it more efficient
- style: change the style view
- test: add new test for testing code
- docs: change docs for guidelines
  
  here's an example for commit message
  ```
  git commit -m "feat: add map screen"
  ```
and this is the guidelines if you have any kind of issues and there are some step to finished it [link](https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/linking-a-pull-request-to-an-issue)
